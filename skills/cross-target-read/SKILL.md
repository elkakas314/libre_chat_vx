# Cross-target read

Use only for explicit or contextual read comparison.

1. Resolve the primary target.
2. Keep TargetOverride read-only and one-turn.
3. Fan out reads independently.
4. Preserve per-target timeout, freshness, revision and provenance.
5. Label partial results.
6. Never broadcast a mutation.
7. Never infer that DONE on one target means DONE on the other.
8. Ask for disambiguation if a material request does not identify its target.
