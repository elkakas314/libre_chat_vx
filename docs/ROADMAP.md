# Roadmap

## P0 — Source/bootstrap
Repository structure, source pin, contracts, CURRENT and handoff.

## P1 — Host preflight
Inspect the real LibreChat root, runtime, DB/storage, auth, PWA/mobile hooks and resource budget. Adopt existing material if present.

## P2 — Upstream overlay
Build a narrow overlay against the exact upstream pin. No source fork sprawl and no secrets in Git.

## P3 — MANOJOS3 R0
Health/readiness/self/capability projection plus one real read and readback.

## P4 — ORÁCULO mediated R0
Use MANOJOS3 as the preferred governed route. Keep ORÁCULO advisory.

## P5 — Cockpit
CurrentFocus, U0–U23, four truth lanes, panels/lenses, lazy projection, backpressure, privacy and accessibility.

## P6 — Governed mutation
One small R2 operation with target authority, execution, readback, verifier and receipt.

## P7 — Mobile/recovery/low-power
PC/mobile continuity, backend-off semantics, reconnect/resync, UNKNOWN_OUTCOME and measured Lenovo resource profile.

## P8 — VX13 runtime
Only when VX13 leaves DESIGN_ONLY and exposes a real Link/runtime contract.
